# Laravel Module — Commands

Commands are typed Data Transfer Objects (DTOs) that carry data between layers. They contain **no business logic**.

## Location

```
app/Modules/{ModuleName}/Commands/
├── Create{ModuleName}Command.php
├── Update{ModuleName}Command.php
├── UpdateStatus{ModuleName}Command.php
└── Search{ModuleName}Command.php
```

## Rules

1. All properties **must** be `readonly`.
2. No methods except `fromRequest()` static factory.
3. No business logic — only data transportation.
4. `fromRequest()` maps the validated request to the command.
5. `Search*Command` always includes `search`, `status`, `limit`, and `offset`.

---

## Create{ModuleName}Command

The `id` property is **always the first property** in Create commands. It carries the UUID generated by the client.

```php
<?php

namespace App\Modules\{ModuleName}\Commands;

use App\Modules\{ModuleName}\Requests\Create{ModuleName}Request;

class Create{ModuleName}Command
{
    public function __construct(
        public readonly string $id,
        public readonly string $name,
        // add fields as needed
    ) {}

    public static function fromRequest(Create{ModuleName}Request $request): self
    {
        return new self(
            id: $request->string('id')->toString(),
            name: $request->string('name')->toString(),
        );
    }
}
```

## Search{ModuleName}Command

Filters are passed as a single `filters` array (criteria pattern). This allows the Repository to iterate over them without the Command needing to know the available filter keys.

`companyId` is a **dedicated nullable property** (not a filter key). Company scoping must travel through the Command so the Repository never has to read `session()`. The Controller fills it from the `{company}` route parameter.

```php
<?php

namespace App\Modules\{ModuleName}\Commands;

class Search{ModuleName}Command
{
    /**
     * @param array<string, mixed> $filters  Associative array of filter criteria (e.g. ['status' => 'active', 'search' => 'foo'])
     */
    public function __construct(
        public readonly array $filters = [],
        public readonly int $limit = 20,
        public readonly int $offset = 0,
        public readonly ?string $companyId = null,
    ) {}
}
```

---

## Instantiation in Controller

Commands are always created in the Controller before being passed to the Service:

```php
// From Request (mutation use cases)
$command = Create{ModuleName}Command::fromRequest($request);

// Inline (search use case — criteria pattern)
// Note: index(Request $request, string $company) — pass the route company into the command.
$command = new Search{ModuleName}Command(
    filters: $request->only(['search', 'status']),
    limit: $request->integer('limit', 20),
    offset: $request->integer('offset', 0),
    companyId: $company,
);
```
